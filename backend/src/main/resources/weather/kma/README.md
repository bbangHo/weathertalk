# 중기예보 구역 코드표 (기상청)

- 출처: 기상청, 「중기예보_중기기온예보구역코드_2025.12.xlsx」 — 공공데이터포털 「기상청_중기예보 조회서비스」 활용가이드 첨부 문서
- 이용허락: 공공누리 제1유형 (출처표시). 앱·서비스에 "기상청" 출처를 표시해야 한다.
- 변환: 엑셀 시트를 그대로 UTF-8 CSV로 저장했다(`kma-mid-temperature-region-codes-2512.csv`). 앞의 세 열이 `예보구역코드, 구역명, 특성`이고, 오른쪽 열은 원본의 특성 범례(A=육상, C=도시/기온, H=해양)라 읽을 때 무시한다. 내용은 고치지 않았다.

## 행정동 → 중기 예보구역 대응표

`../neighborhood-mid-term-regions.csv`는 이 코드표와 기상청 행정동 자료(`neighborhood/kma/kma-administrative-dong-2607.csv`, 3,564개)를 **이름으로 맞춰 생성**한 표다. 사람이 고치지 않는다.

- 생성기: `src/test/java/kr/weathertalk/weather/internal/region/MidTermRegionTableGenerator.java`
- 검증·재생성: `MidTermRegionTableTests` — 저장소의 표가 생성 결과와 같은지 확인하고, 매칭 요약을 테스트 출력에 남긴다. 다시 만들려면
  `REGENERATE_MID_TERM_REGIONS=true ./gradlew test --tests '*MidTermRegionTableTests'` (backend 디렉터리에서 실행).
- 시도 대표 지점: `../mid-term-region-sido-defaults.csv` (생성 폴백과 런타임 폴백이 함께 쓴다)

### 매칭 규칙

1. 섬 지점은 읍면동 이름으로 맞춘다: 옹진군 백령면 → 백령도, 신안군 흑산면 → 흑산도, 제주시 추자면 → 추자도, 울릉군 독도 → 독도.
2. 기온 지점(특성 C)은 시군구 이름으로 맞춘다. 일반구가 있는 시는 앞의 시 이름(`수원시장안구`→수원, `청주시흥덕구`→청주, `포항시남구`→포항), 그 밖에는 시·군·구 접미어를 뗀 이름(`가평군`→가평, `울릉군`→울릉도). 지점 코드 체계로 정해지는 시도 묶음 안에서만 찾는다(경기 `광주시`→광주 11B20702, 강원 `고성군`→11D20402, 경남 `고성군`→11H20404). 접미어를 떼기 전 이름이 같은 지점이 있으면 그것을 쓴다.
3. 못 맞추면 광역시·통합특별시의 자치구는 그 도시 지점(CITY_DISTRICT), 나머지는 시도 대표 지점(SIDO_FALLBACK).
4. 육상 구역(특성 A)은 기온 지점 코드로 정한다: 서울·인천·경기 11B00000, 강원 영서 11D10000(11D1 지점)·영동 11D20000(11D2 지점: 강릉·동해·삼척·속초·고성·양양·태백), 충북 11C10000, 대전·세종·충남 11C20000, 전북 11F10000, 광주·전남 11F20000, 대구·경북(울릉도 포함) 11H10000, 부산·울산·경남 11H20000, 제주 11G00000.

### 생성 결과 (행정동 2607 × 코드표 2512)

| 매칭 | 행정동 수 | 내용 |
|---|---:|---|
| NAME | 2,408 | 시군구 182개가 이름으로 기온 지점과 맞음 |
| CITY_DISTRICT | 1,120 | 서울·부산·대구·인천·대전·울산과 전남광주통합특별시(옛 광주)의 자치구 69개 → 그 도시 지점 |
| DONG_ALIAS | 4 | 백령면·흑산면·추자면·독도 |
| SIDO_FALLBACK | 32 | 대구 달성군 → 대구, 부산 기장군 → 부산, 울산 울주군 → 울산, 인천 옹진군(백령면 제외) → 인천 |

검토가 필요한 사례:

- **순천**: 코드표에 `11F20405 순천시`와 `11F20603 순천`이 둘 다 있다. 시군구 이름과 정확히 같은 `순천시`(11F20405)를 쓴다.
- **인천 옹진군**: 백령면만 백령도 지점이고, 대청면(백령도 인근)·연평면·덕적면 등은 인천 지점으로 폴백한다.
- **쓰이지 않는 지점**: 추풍령, 대관령, 성산, 성판악, 고산, 이어도, 산천단, 한남, 순천(11F20603)과 북한 지점들. 대관령(11D2, 영동)은 평창군 대관령면에 맞출 수 있지만 평창군의 육상 구역(영서)과 어긋나 쓰지 않았다.
