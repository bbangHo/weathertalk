# 에어코리아 대기질 자료 (한국환경공단)

- 출처: 환경부/한국환경공단 에어코리아 — 공공데이터포털 「한국환경공단_에어코리아_대기오염정보」, 「한국환경공단_에어코리아_측정소정보」 오픈API
- 기준 문서: 「에어코리아 오픈API 활용가이드 — 대기오염정보 조회 서비스」 v1.4(2026-07-01), 「측정소정보 조회 서비스」 v1.2(2023-10-23)
- 이용허락: **공공누리 제3유형 — 출처표시 + 변경금지**. (기상청 자료는 제1유형 출처표시, `../kma/README.md`)
- 이 폴더에는 자료 파일을 두지 않는다. 측정소 목록·측정값은 실행 중 API로 받아 DB(`weather_air_station`, `weather_air_measurement`)에 둔다.

## 쓰는 기능

| 기능 | 오퍼레이션 | 요청 | 주기 |
|---|---|---|---|
| 측정소 목록 조회 | `MsrstnInfoInqireSvc/getMsrstnList` | `ver=1.1`(dmX=경도, dmY=위도 WGS84), `numOfRows`=`weather.source.air-korea.page-size`, 페이지는 `totalCount`까지 | 하루 1회(`weather.air.station-sync-interval`), 기동 시 목록이 비었으면 1회 |
| 시도별 실시간 측정정보 조회 | `ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty` | `sidoName=전국`, `ver=1.3` | 매시 + `weather.air.availability-delay` (필요할 때만) |

근접측정소 목록(`getNearbyMsrstnList`)·측정소별 실시간 측정(`getMsrstnAcctoRltmMesureDnsty`)은 활용 승인은 유지하지만 코드에서 부르지 않는다
(동네·측정소마다 호출해 개발계정 기능별 하루 500건 한도를 금방 쓰기 때문). 동네 → 측정소 대응은 측정소 목록으로 PostGIS 최근접을 계산한다.

## 변경금지(제3유형) 준수

- 측정값(PM10·PM2.5 농도)과 등급은 받은 값을 **그대로** 저장·응답한다. 단위 환산·반올림·보정·평균을 하지 않는다. 결측("-")은 없음으로 두고 0이나 다른 값으로 채우지 않는다.
- 등급은 에어코리아가 준 등급 코드(1 좋음 · 2 보통 · 3 나쁨 · 4 매우나쁨, `pm10Grade`·`pm25Grade` = 24시간 등급)를 그대로 쓴다.
  등급이 비어 있고 농도만 있을 때만 환경부 공식 기준 경계(PM10 30/80/150, PM2.5 15/35/75 ㎍/㎥)로 판정한다(자체 기준을 만들지 않는다).
- 통합 미세먼지 등급은 위 두 공식 등급 중 나쁜 쪽을 고를 뿐 새 수치를 만들지 않는다.
- 측정소명·측정 시각을 함께 응답해 어느 측정소의 언제 값인지 바꾸지 않고 보여 준다.

## 앱·서비스 표기 의무 (활용가이드 3.2 준수사항, 약관 제7조·제8조)

- 대기질을 보여 주는 화면에 출처를 표시한다: 예) "자료: 환경부/한국환경공단 에어코리아 (공공누리 제3유형)".
- 실시간 자료는 인증을 받지 않은 자료라 통신 장애·측정기기 이상 등으로 실제와 다를 수 있음을 함께 알린다.
- 받은 자료를 별도 서비스 없이 그대로 제3자에게 재제공하지 않는다(약관 제5조 4호).
- 개발계정은 신청 후 1년 안에 운영계정 전환(개발보고서 제출)이 필요하다(약관 제11조 4항).
