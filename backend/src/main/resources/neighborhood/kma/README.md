# 행정동 기준 데이터 (기상청)

- 출처: 기상청, 「기상청41_단기예보 조회서비스_오픈API활용가이드_격자_위경도(2607).xlsx」 — 공공데이터포털 [기상청_단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do) 참고문서
- 이용허락: 공공누리 제1유형 (출처표시). 앱·서비스에 "기상청" 출처를 표시해야 한다.
- 변환: 원본에서 읍·면·동 단위 행(3단계가 있는 행) 3,564개만 추렸다. 경도·위도는 원본의 `경도(초/100)`·`위도(초/100)`(십진 도) 값이다.

| 컬럼 | 원본 컬럼 |
|---|---|
| code | 행정구역코드 (10자리 행정동 코드) |
| sido_name / sigungu_name / eupmyeondong_name | 1단계 / 2단계 / 3단계 |
| grid_nx / grid_ny | 격자 X / 격자 Y |
| longitude / latitude | 경도(초/100) / 위도(초/100) — 행정동 대표점 |
| location_updated | 위치업데이트 |

경계(폴리곤)는 포함되어 있지 않다. 동네 판정은 대표점 기준이다 (ADR 0016).

갱신: 기상청이 활용가이드를 새로 올리면(파일명 끝 YYMM) 같은 방식으로 변환해 새 버전으로 적재하고, 적재기의 신설·변경·폐지 비교 보고서를 확인한다.
